## Highlights

The first published release of this fork of Eglantine. It adds a built-in MCP server so AI agents and scripts can drive and inspect the emulator, brings in the upstream and PokeDinner work, and makes a large performance pass on Switch 2 titles. Donkey Kong Bananza's open map goes from about 14.5 fps to about 25 fps on the test machine, and the view facing away from it from about 42 fps to the 60 fps cap.

- **Donkey Kong Bananza:** faster, no longer purple, solid ground, and a crash on the GPU thread fixed.
- **Built-in MCP server:** boot games, send input, take screenshots, read logs and memory, set breakpoints, profile and record routes from an AI agent or a script. Off by default.
- **GPU thread work:** GPU-culled draws run on the host GPU, caches stop redoing work that did not change, and many per-draw costs are gone.

Numbers are from one machine and one benchmark route, so expect different results on other hardware and in other games.

## New Features

- **Built-in MCP server** (Model Context Protocol), off by default and loopback only, with Allow Writes and an optional token to gate state changes:
  - Boot and stop games, screenshots, input and frame-exact TAS.
  - An event timeline of logs, crashes and unimplemented service commands with backtraces.
  - Guest memory read, search, watch and scan; threads and backtraces; IPC and SVC tracing; settings.
  - Breakpoints and watchpoints through the GDB stub, shader and macro dumps, crash reports, the FS access log.
  - Recorded routes with screen fingerprints, benchmarks, visual baselines, and `ab_test` to measure what a setting changes.
  - `host_profile`: a sampling profiler for the emulator's own threads, symbolized from the PDB on Windows.
  - `set_activity`: an agent can show what it is doing in the status bar.
  - Configure > Debug > MCP, a Tools > MCP Server menu, a status bar label, a read-only browser dashboard, and `eden-cli --mcp` for headless runs.
  - `docs/MCP-tools.md` documents every tool.
- **Draw merging:** consecutive draws of identical state are recorded as one multi-draw (VK_EXT_multi_draw or multi-draw indirect). Built for games with runs of identical-state draws such as UI, text, particles and foliage. Donkey Kong Bananza does not benefit, since its draws each bring their own data. `EDEN_NX2_MERGE_DRAWS=0` turns it off.
- **Bindless textures (experimental, off by default, `EDEN_NX2_BINDLESS=1`):** graphics pipelines can sample textures from one global texture heap. It renders Donkey Kong Bananza correctly but is about 0.5 fps slower there for now, so it stays off.
- **From PokeDinner** (Franseven/PokeDinner-a-Eglantine-Fork): sparse terrain arrays bound layer by layer, AMD sparse-region and RDNA fixes, Switch 2 ASTC limits and partial re-uploads, texture format mappings (X8Z24, G8R24), TXQ from any descriptor buffer, NVN mapping modify, shader reuse and pipeline work, the Donkey Kong Bananza 30 fps lock checkbox, Mario Kart World 30 fps and dynamic fps modes, and a remembered recommended-settings prompt.
- **From upstream Eglantine** (210 commits): game DLSS network emulation with health checks and a replacement upscale (Fortune's Weave), native geometry shaders, more Ampere instruction forms, SUST with partial channel masks, storage buffer tracking that stops at loaded pointers, zero-copy chunked texture uploads, a guard against garbage draw counts, the NUP metadata editor, and the Hyrule Warriors and Fast Fusion fixes.

## Improvements

Donkey Kong Bananza's open map, measured along the way:

| Change | Open map |
| --- | --- |
| Start | 14.5 fps |
| GPU-culled draws on the host GPU | 17.5 fps |
| Texture alias sync skipped when no alias changed | 18.7 fps |
| Macro register writes sent in batches | 21.4 fps |
| Value-based caches, batched record resets and smaller fixes | about 25 fps |

- **GPU-written draw records are drawn indirectly.** The game's culling pass writes a record per mesh, and reading each one on the CPU forced the two GPU threads and the host GPU to take turns about 2,100 times a frame. The host GPU now reads them directly, and split drains fall from about 31,700 to about 1,200 a second.
- **Texture binding cache:** draws reuse their image views, samplers and descriptors while the values they came from compare equal (92% of draws in Donkey Kong Bananza). `EDEN_NX2_BINDCACHE=0` turns it off.
- **Writes of unchanged bytes skip cache invalidation.** About 60% of inline and constant buffer writes in Donkey Kong Bananza changed nothing. `EDEN_NX2_INLINE_SAME=0` turns it off.
- **Vertex and index buffer binds skip synchronization while nothing changed** (about 1.3 million a second). `EDEN_NX2_SYNC_MEMO=0` turns it off.
- **Indirect record resets are written in one batch.** `EDEN_NX2_RESET_BATCH=0` turns it off.
- **A draw with unchanged pipeline state reuses the previous pipeline** without rebuilding its key, and identical bindings record nothing. `EDEN_NX2_KEY_GATE=0` turns the first off.
- **Register writes are cheaper:** macro writes travel and execute as batches, and the GPU split's threads no longer share cache lines.
- **Uniform buffers:** each slot reuses its previous allocation when the bytes match, and an address seen for the first time is copied once instead of twice.
- **Smaller per-draw savings:** query cache lookups skip their lock for pages without queries, range sets skip no-op changes, the Vulkan worker is woken less often, LRU touches check first, and submissions come every 512 draws instead of 128 on Switch 2 titles.
- **HMMA (tensor) is emulated by default** with f32 accumulation, also outside recognized game DLSS evaluations.
- **Macro parameters on CPU-written pages no longer drain the GPU split.**
- **The window title** shows the build again, with `| Quixomatic fork` at the end.
- **Profiling:** split drains by site, draw counters and many new NX2 profiler counters.

## Fixes

- **Donkey Kong Bananza no longer renders purple:** the old f16 HMMA chain overflowed to inf or NaN in its upscaler.
- **Donkey Kong Bananza's see-through ground** renders solid (from PokeDinner).
- **Intermittent crash recording Vulkan commands with the GPU thread split** (access violation in `Scheduler::Record`, about 2 of 3 benchmark runs).
- **The render area push constant overwrote the texture rescaling bits,** and shaders using both had two push constant blocks, which Vulkan does not allow.
- **Rectangle textures were queried as 1D.**
- **Indirect draws mark their argument buffer as used,** so a later upload in the same batch is not reordered ahead of the draw.
- **eden-cli:** `-d`/`--debug` and `-i`/`--input-profile` no longer crash on launch, and TAS advances.
- **Switch 2 module names are found,** so backtraces are symbolized.
- **Merge duplicates and stale tests** left by the upstream and PokeDinner merges are gone.

## Under the hood

- **Release pipeline:** releases build from semver tags on `release` and use curated notes or the changelog as their body. A compiler warning no longer fails a release build, the MSYS2 setup retries when a package mirror stalls, and a platform that fails no longer holds back the others (the notes list what is missing).
- **Build fixes** for GCC: an unused variable in partial texture re-uploads, and warnings in the HMMA lowering and the AArch32 fatal context.
- **Tests** for range sets and uniform reuse; existing tests updated for the merged behaviour.

## Known issues

- One benchmark run ended with a failed stop, and a later run under ProcDump hung while stopping: the game panicked in an audio thread during shutdown, the emulation thread missed its time limit, and force-terminating it deadlocks. It has not come back in normal runs since. If stopping a game ever hangs, closing the emulator from the task manager is safe.
- Without robustness2 `nullDescriptor`, fallback null image views are all 1D views.
- Only Windows with an NVIDIA GPU has been tested for this release's performance work. Merged multi-draws are not exercised by Donkey Kong Bananza; `EDEN_NX2_MERGE_DRAWS=0` turns them off if a game misrenders.
