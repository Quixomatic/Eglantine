## Highlights

The Legend of Zelda: Ocarina of Time is playable: scene, grass and foliage render at full resolution with no white flashing, and the forest runs at about 37 fps, up from about 21 when it first rendered. Most of the work is hand ported from the Lichii fork (zortos293/Lichii), on top of this fork's own GPU optimizations.

- **Ocarina of Time:** reaches gameplay, renders its scene, minimap, grass and foliage, and no longer flashes white.
- **Faster Switch 2 rendering:** fewer submissions and render passes, a GPU thread split that sleeps instead of spinning, fewer waits on semaphores and command lists, and faster guest CPU timing.
- **Crash fix:** the null image view crash in v0.1.32 and v0.1.33 is fixed.

Numbers are from one machine and one route, at default settings. Donkey Kong Bananza was not measured in this release.

## New Features

- **Built-in "Max Resolution" patch for Ocarina of Time**, listed under Add-Ons, where it can be turned off.
- **Experimental fast draw and parallel recording**, off by default as in Lichii: `EDEN_NX2_FAST_DRAW=1` (or `=2`) and `EDEN_NX2_PARALLEL_RECORD=1`.
- **Upscaler stand-in for Ocarina of Time on Mesa's Intel driver**, where its tensor programs are too slow to emulate.

## Improvements

- **Ocarina of Time shaders:** Lichii's lowering work (bloom, gathers, depth-compare, register shadows, uniform loads of 8 and 16 bits, global compare-and-swap and more). The game's compute programs no longer get rejected.
- **Grass and foliage:** storage buffers behind dynamic and loaded pointers, and pointer table pools up to 64 MiB.
- **Fewer submissions and render passes:** Switch 2 titles submit every 4096 draws, and a fragment barrier ends a render pass only when the next draw needs it.
- **Less waiting on the GPU thread split:** the front sleeps instead of spinning, and semaphore acquires that are already met skip the wait. Command list and macro reads wait only for the writes they depend on, draw-written command pages flush in one round trip, and constant buffer writes are batched.
- **Guest CPU timing:** the system counter is read inline, ordered loads and barriers are cheaper on x86-64, and idle cores spin briefly before sleeping.
- **Buffers and textures:** CPU reads of GPU results download in one batch, GPU writes copy back only what the CPU reads, and CPU writes next to GPU data upload in place. Clean buffers skip upload scans, a render target a clear overwrites is not uploaded first, and empty draws are skipped.
- **Nanosecond GPU timestamps for Switch 2 titles.** Boost and Overclock scale their GPU time.
- **Video:** AV1 prefers dav1d and falls back to CPU decoding if the hardware decoder fails.
- **Pipelines:** used pipelines are kept for 16 sessions and saved every 15 seconds, and alpha test references are rounded so fewer pipelines are built.

## Fixes

- **White flashing in Ocarina of Time:** guest CPU reads of GPU results (occlusion counts) were stale. The occlusion counter also pauses instead of resetting at each submission.
- **Crash preparing the null image view** (present since v0.1.16).
- **Black screen in Ocarina of Time:** shader reuse hid native programs from translation, and the upscaler's last pass was rejected.
- **Split thread deadlock** when a fence wait found its commands still deferred.
- **FSR3 frame generation** interpolates between the previous and current frame.
- **More fixes from Lichii:**
  - draws after a failed pipeline build are dropped;
  - AMD's demote reorder handles nested returns;
  - a dirty memory race in video decoding is fixed;
  - depth-stencil reinterpret copies are valid;
  - the swapchain waits for the device before it is recreated.
- **Event waits** no longer return early on AMD (MWAITX), newer Intel (UMWAIT) or older Intel CPUs.
- **Switch 2 XCI games** get the Switch 2 clock.
- **From upstream:**
  - command lists wait for queued GPU maps (Pokopia);
  - MKW frame pacing checks the presenting process;
  - an out-of-date swapchain acquire returns at once.
- **Loading:** RomFS falls back to the loaded one for program index 0, and a failed ZBIC segment fails the load cleanly.

## Under the hood

- **Shader cache version 24:** every game rebuilds its shader cache once.
- **Off switches:** every performance change has an `EDEN_NX2_*` off switch, listed in `CHANGELOG.md`.
- **Not taken from Lichii:**
  - forced per-game settings for Ocarina of Time;
  - its fog workaround;
  - experiments it marks as not ready.

## Known issues

- **Donkey Kong Bananza has not been measured** since v0.1.33. Most of these changes apply to every Switch 2 title.
- **Ocarina of Time:** outdoor fog is too bright and water shows blotches; both are still open upstream too.
